# Security policy

## Reporting a vulnerability
Please report security problems privately through GitHub: **Security → Report a vulnerability**
on this repository. Don't open a public issue. Reports are answered as soon as possible; this is a
volunteer project with no fixed response time.

In scope: our code, build scripts and CI (for example a crafted `Data/` file that crashes or
exploits the reimplementation, or a workflow that leaks a token).

Out of scope: the original game, its executables and DLLs, and its copy protection. This project
does not work on or discuss the copy protection in any way (see `CONTRIBUTING.md`).

## Supported versions
Only the latest `main` is supported; there are no releases yet.
