## Verification
Every reimplemented function has a differential test in `tests/` that compares it with the
original export on the same inputs. Float results must match bit for bit unless a comment
justifies a tolerance.

## Log
- 2026-10-17: Files, part 2: `TNativeFile`/`TNativeFileSystem` (Win32 files with a 2 KB sector
  read buffer). Quirks kept: `Open` disables write buffering, `GetSize` moves the OS file
  pointer, directory scans leak the find handle. Verified against the original on real files.
- 2026-10-17: Files, part 1: `TFile`, `TFileSystem`, `TFileManager` (mounting, system path,
  name resolution, path helpers), `TMutex`/`TMutexLock` and the inline `TDList<T>` template.
  The original manager drives our C++ file systems in the differential test (same vtables).
- 2026-10-17: Containers complete: `TGenericDList`, `TGenericPriList`, `TGenericNTree`, `TBitArray`
  (with `TGenericNodeList` earlier). Template containers (`TMap`, ...) are inline in the original
  and will be added header-only where they are used. TKernelInterface passes 50% coverage.
- 2026-10-17: Containers, part 1: `TGenericNodeList` (intrusive circular list with a sentinel
  node) with its `TNode` and `Iterator`, verified by randomised insert/remove/append runs.
- 2026-10-17: RTTI: `TObject` and `TClass` (class tree, lookup, IsA, common base, tree walks),
  verified on randomised class trees built by the original. Global `operator new`/`delete` now
  route to `tmalloc`/`tfree`, as the original inlines them (TObject's deleting destructor calls
  `tfree`). Localised strings and `TLocale` wait for containers, files and events (#7 blocked).
- 2026-10-17: Strings, part 3: `TWStringPool`, `TPooledWString` and the inline `TPWString`; both
  pools now share one sorted-array helper (`StringPoolArray.h`). `coverage.py` ignores header-only
  classes (the original inlines `TPWString`) and our `jpog::` helpers.
- 2026-10-17: Strings, part 2: `TCStringPool`, `TPCString`, `TPooledCString` (string interning
  with reference counts). Quirk kept: the pool destructor skips every other entry while removing.
  Fixed an exit-time crash: allocator state is now never destroyed, since static free lists free
  memory during exit. `ReadFile`/`WriteFile` wait for `TFile` (#10).
- 2026-10-17: Strings, part 1: `TCString`, `TWString` and the `TSystem` string/memory helpers
  (143 functions). Randomised differential runs compare contents, length and spare capacity after
  every operation. Quirk kept: `TWString` copying onto itself zeroes its characters (no
  self-assignment check, unlike `TCString`).
- 2026-10-17: Memory, part 2: TMemory statistics (`GetMemInfo` reports live allocations) and the
  debug/HAL functions, most of which are empty stubs in the shipped original.
- 2026-10-17: Memory, part 1: `tmalloc`/`tcalloc`/`trealloc`/`tfree`, the core `TMemory` API and
  `TFreeList` (exact; its pool layout matches the original in randomised differential runs).
  Finding: the original `TMemory::Realloc`/`Recalloc` are stubs returning null.
- 2026-10-17: `TMath::Get/SetFPUControlWord` reimplemented (x86: real `fnstcw`/`fldcw`; x64: stored
  value). Contrary to the earlier note, Set is not a no-op. No module imports either function.
- 2026-10-17: `TMatrix44`, `TPlane` and `TQuaternion::GetEulerXYZ` reimplemented (108 functions);
  issue #4 complete. The exact x87 evaluation order of the large functions (Invert4,
  InvertArbitrary, MatToQuat, ...) was recovered with the new `tools/x87_expr.py`, and all
  171,000 differential assertions matched on the first run.
- 2026-10-17: `TQuaternion` reimplemented (46 functions and its constants; `GetEulerXYZ` follows
  with `TMatrix44`). Findings: `operator/=(TQuaternion)` divides z by y (an original bug, kept);
  `TMath::ACos` and friends return their double result in ST0, so callers that use it directly
  (Slerp) see a double, not a float; fsin/fcos results are extended precision. About 100,000
  differential assertions match bit for bit.
- 2026-10-17: `TVector4` reimplemented (all 78 exported members and the 7 constants). Most
  operations only touch x, y and z; two-operand forms copy w from the first operand. Max/Min tie
  handling matches the original's comparisons; about 160,000 new differential assertions match
  bit for bit.
- 2026-10-17: **Launch 1.** Our `jpog.exe` (WinMain + `AApplication`) links against the original
  engine DLLs via generated import libraries and opens the game's Direct3D 8 window. Exiting
  still crashes in the renderer teardown (tracked in an issue).
- 2026-10-17: `TVector2` and `TVector3` reimplemented (all 119 exported functions plus the static
  constants). About 250,000 differential assertions match the original bit for bit. The diagonal
  constants (`VEC_POSXPOSZ`, ...) turned out to be unit length.
- 2026-10-17: Phase 0 complete (symbols, build skeleton, repo, CI).
- 2026-10-17: `Toshi::TMath` scalar functions reimplemented and verified bit for bit against
  the original `TKernelInterface.dll` at gameplay precision. Finding: D3D8 is created without
  FPU_PRESERVE, so the game's x87 math runs at 24-bit precision; plain float arithmetic
  reproduces it exactly.
