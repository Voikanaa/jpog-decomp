## Verification
Every reimplemented function has a differential test in `tests/` that compares it with the
original export on the same inputs. Float results must match bit for bit unless a comment
justifies a tolerance.

## Log
- 2026-10-17: `TMatrix44`, `TPlane` and `TQuaternion::GetEulerXYZ` reimplemented (108 functions);
  issue #4 complete. The exact x87 evaluation order of the large functions (Invert4,
  InvertArbitrary, MatToQuat, ...) was recovered with the new `tools/x87_expr.py`, and all
  171,000 differential assertions matched on the first run.
- 2026-10-17: `TQuaternion` reimplemented (46 functions and its constants; `GetEulerXYZ` follows
  with `TMatrix44`). Findings: `operator/=(TQuaternion)` divides z by y (an original bug, kept);
  `TMath::ACos` and friends return their double result in ST0, so callers that use it directly
  (Slerp) see a double, not a float; fsin/fcos results are extended precision. About 100,000
  differential assertions match bit for bit.
- 2026-10-17: `TVector4` reimplemented (all 78 exported members and the 7 constants). Most
  operations only touch x, y and z; two-operand forms copy w from the first operand. Max/Min tie
  handling matches the original's comparisons; about 160,000 new differential assertions match
  bit for bit.
- 2026-10-17: **Launch 1.** Our `jpog.exe` (WinMain + `AApplication`) links against the original
  engine DLLs via generated import libraries and opens the game's Direct3D 8 window. Exiting
  still crashes in the renderer teardown (tracked in an issue).
- 2026-10-17: `TVector2` and `TVector3` reimplemented (all 119 exported functions plus the static
  constants). About 250,000 differential assertions match the original bit for bit. The diagonal
  constants (`VEC_POSXPOSZ`, ...) turned out to be unit length.
- 2026-10-17: Phase 0 complete (symbols, build skeleton, repo, CI).
- 2026-10-17: `Toshi::TMath` scalar functions reimplemented and verified bit for bit against
  the original `TKernelInterface.dll` at gameplay precision. Finding: D3D8 is created without
  FPU_PRESERVE, so the game's x87 math runs at 24-bit precision; plain float arithmetic
  reproduces it exactly.
